## 📌 Описание проекта

![Гусеничный самовар «Пыхтун»](pyhtun.png)
*Иллюстрация: машинист ведёт «Пыхтуна» через Каменный перевал — гусеничный ход, медный котёл-корпус, бур-носик, топка и обязательная чашка чая.*

Гусеничный самовар «Пыхтун» — уникальное паровое наземное средство передвижения. Огромный медный котёл на двух гусеницах оснащен буровым носиком. Топка, кипятящая воду для чая, одновременно вырабатывает пар для движения, поэтому каждая поездка и каждая кружка ароматного чая расходуют единый запас пара.

Проект моделирует сложную доменную логику управления транспортом: движение в различных средах (дорога, песок, подземное бурение, брод в воде), преодоление препятствий (канавы, валуны, узкие мосты), аварийные ситуации (камнепады и поломки гусениц), а также заправку топливом (шишками) и заваривание чая.

## 🗂 Структура репозитория и навигация

В репозитории проекта содержатся следующие ключевые файлы и директории:

* **`tracked_samovar.py`** — **основной модуль реализации** в корне репозитория: класс `TrackedSamovar`, иерархия исключений, константы и коэффициенты сред.
* **`demo_script.py`** — **демонстрационный скрипт**, полностью автоматизирующий показательный сценарий работы самовара.
* **`tests/`** — набор модульных и сценарных тестов на базе `unittest` (`test_tracked_samovar.py`).
* **`SPEC.md`** — детальное техническое задание на проект.
* **`TEST_CASES.md`** — спецификация тест-кейсов.
* **`PRESENTATION.md`** — презентация проекта и логирование демонстрационного прогона.
* **`BUGREPORT.md`** — вопросы к ТЗ от разработчика.
* **`FIXES.md`** — журнал исправлений реализации.
* **`README.md`** — текущая документация проекта.

## 🚀 Как запустить тесты и демонстрацию

### 1. Запуск тестов
Для проверки работоспособности реализации по всем тест-кейсам ТЗ выполните команду из корня репозитория:
```bash
python3 -m unittest discover tests
```

### 2. Запуск демонстрационного сценария
Чтобы увидеть демонстрацию всей функциональности в консоли (поездки, переходы по средам, преодоление препятствий, заварка чая и перехват исключений), запустите демо-скрипт из корневой директории проекта:
```bash
python3 demo_script.py
```
